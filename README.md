# Personal Expense Tracker

> 🚧 Work in progress — currently in design phase

Expense Tracker is a web app for individuals who want visibility into their spending.
Users log expenses with an amount, category, and date, then see monthly summaries and category breakdowns to understand where their money goes.
It solves the problem of "I don't know why I'm broke at the end of the month" without the complexity of a full budgeting suite.

## Tech stack
React · Spring Boot · PostgreSQL
