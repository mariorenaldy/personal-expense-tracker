# Personal Expense Tracker

Expense Tracker is a web app for individuals who want visibility into their spending. 
Users log expenses with an amount, category, and date, then see monthly summaries and category breakdowns to understand where their money goes. 
It solves the problem of "I don't know why I'm broke at the end of the month" without the complexity of a full budgeting suite.

### User stories:
1. As a user, I can register and log in so my data is private to me 
2. As a user, I can add an expense with amount, category, date, and optional note 
3. As a user, I can edit or delete an expense I created 
4. As a user, I can view my expenses in a list, filtered by month and category 
5. As a user, I can see a monthly total and a category breakdown chart 
6. As a user, I can create, rename, and delete my own categories 
7. As a user, I can see sensible defaults (starter categories) when I first sign up 
8. As a user, I see clear empty states when I have no expenses yet 
9. As a user, I can compare this month's spending to last month's

### Out of scope for v1:
income tracking, recurring expenses, budgets/alerts, multi-currency, receipt uploads, data export, dark mode, user delete.

`USER`
